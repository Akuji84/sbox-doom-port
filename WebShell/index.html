Getting started

            
Double-click the DOOM folder on the desktop and pick a game. Run CONTROLS.EXE in that folder to set your keys - they apply in-game.

            
Things to try

            
- Internet Explorer really browses: visit leaderboards.akuji.org for live rankings.

            
- Network Neighborhood shows who is online; Messenger (Start > Programs) lets you chat with them.

            
- Start > Programs > Games has Minesweeper, Solitaire and FreeCell if the demons get too much.

            
- Right-click the desktop for wallpapers, screen savers and color schemes.

            
Found a problem?

            
Start > Programs > Bug Report Wizard sends it straight to the developer.

Getting started

                    
Double-click a program in the C:\DOOM folder to play. Your control bindings and settings on this screen apply to every game.

                    
Moving around

                    
Move Forward / Backward walks; hold Run to sprint. Strafe Left / Right side-steps, which is faster and safer than turning to dodge projectiles.

                    
Turn Left / Right rotates you. If you play with the mouse, turning is usually easier by moving the mouse and keeping your hands on strafe keys.

                    
Fighting and doors

                    
Fire shoots your current weapon. Weapon 1-7 selects weapons - all seven slots are rebindable below. Use / Open Door opens doors, flips switches and activates lifts - if something looks like a switch, walk up and press Use.

                    
Tips

                    
- Hold Strafe Mode to turn your Turn keys into strafe keys, the classic 1993 way.

                    
- Always run in Settings removes the need to hold the Run key. Almost everyone plays this way.

                    
- Secrets hide behind misaligned or discolored wall textures. Press Use on suspicious walls.
