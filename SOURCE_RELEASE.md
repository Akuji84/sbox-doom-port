## Contents and build

- `Code`: Managed Doom, host/network/UI adapters, MeltySynth and project file.
- `Editor`, `ProjectSettings`, `Assets/game.scene`, `doom_port.sbproj`: editor,
  scene and package definitions. Compiled caches are regenerated by s&box.
- `Assets/doom`: Freedoom/FreeDM and Freedom Scoops IWADs, soundfont, licenses and credits.
- `WebShell`: external launcher's editable HTML, CSS and JavaScript, with its
  upstream notice. See its README for setup.
- `tests/Regression`: independent gameplay regression harness and stubs.
- `tools`: release inventory/notice verification.

Install the s&box editor and .NET 10 SDK. Open `doom_port.sbproj` in the editor,
let it generate local project files if necessary, open `Assets/game.scene` and
press Play. The game uses a separately hosted web launcher; see below for the
offline engine check. For command-line C#/Razor compilation:

```powershell
dotnet build Code/doom_port.csproj -p:SboxInstallDir="C:/path/to/sbox"
```

For an SDK with its managed assemblies in a different directory, set
`-p:SboxManagedPath="C:/path/to/managed"`. The project does not ship these SDK
assemblies. Sandbox.Generator is required; CodeUpgrader is used when available.
The source targets .NET 10 and C# 14. Use SDK assemblies matching your editor.

```powershell
python tools/verify_release_assets.py
dotnet run --project tests/Regression/Regression.csproj -- .
```

The test harness requires .NET 9 and reads the bundled Freedoom and Freedom
Scoops files. It exercises saves/input/multiplayer helpers, campaign rendering,
level exits, four-player simulation and switching back to the original game.

## Hosted features

The game uses HTTP services for its launcher, leaderboards, analytics and bug
reports. Client requests and response models are in `Code/ManagedDoomHost`;
browser requests are in `WebShell/js`. To connect your own services, update
the endpoint constants and implement the corresponding API contracts.

For a launcher-independent engine check, set `StartInShell` in
`SboxManagedDoomPanel.razor` to false and run the scene.
